# 04. 캐릭터 모델과 애니메이션

> 상태: **CC0 실사형 인간 베이스 적용 완료.**
> 실게임 증거: [`evidence/game/human-realism.png`](evidence/game/human-realism.png)

## 현재 구현

| 항목 | 적용 내용 |
|---|---|
| 인간 베이스 | MakeHuman 1.3 core assets로 생성한 동아시아 남성형 메시 |
| 디테일 | 실제 얼굴형·피부 텍스처·눈·눈썹·머리카락·손가락·신발 |
| 리그 | 104본 스킨 리그를 유지한 GLB |
| 조선 외형 | 게임 제작 저고리 몸통·두루마기 자락·띠·갓·환도 오버레이 |
| 역할 변형 | 플레이어 청색, 주민 적색 계열, 도적 암적색 재질과 머리싸개 |
| 동작 | 속도 기반 상하 움직임·좌우 체중 이동, 공격 시 상체 기울기와 무기 스윙 |

외부 게임의 모델·텍스처·캐릭터 디자인은 복제하지 않았다. 사람 베이스는 MakeHuman 공식 core assets만 사용했고, 조선 의복과 무기는 Godot 기본 메시로 직접 구성했다.

## 생성·가져오기 파이프라인

1. GUI 없는 `makehuman-mcp 0.1.3`로 성별·나이·체형·동아시아 얼굴 계수와 core hair/eyes/skin/clothes를 조합한다.
2. MakeHuman FBX의 팔 자세를 Blender 4.2 LTS에서 자연스러운 A-포즈로 교정한다.
3. Y-up·데시미터 축척을 Godot용 Z-up·미터 축척으로 변환한다.
4. 피부·눈·머리 텍스처를 포함하고 104본 스킨을 보존한 `joseon_male.glb`로 내보낸다.
5. 플레이어·주민·도적은 같은 GLB를 인스턴스화하고 의복 색·갓·머리싸개·무기를 역할별로 조합한다.

최종 빌드는 생성 도구나 AGPL 소스 코드를 포함하지 않는다. MakeHuman 공식 문서는 core assets와 파생 자산을 [CC0](https://static.makehumancommunity.org/about/license.html)로 명시한다. 최종 GLB의 SHA-256은 `data/license-ledger.csv`에서 고정한다.

## 성능·동작 결정

- 한 개의 GLB를 모든 인간형 캐릭터가 공유해 중복 메시와 텍스처 메모리를 피한다.
- 실게임에서는 래퍼 노드만 움직여 걷기 체중 이동과 공격 상체 동작을 만든다. 스킨 리그는 이후 세부 보행·표정 애니메이션을 추가할 수 있도록 보존한다.
- 충돌과 전투 판정은 기존 `CharacterBody3D`·캡슐 충돌체를 유지하므로 외형 교체가 게임 규칙을 바꾸지 않는다.
- 3인칭 카메라는 4.6m로 당겨 얼굴·손·갓이 실제 플레이 화면에서 식별되게 했다.

## 알려진 한계

- 두루마기 자락은 실시간 천 시뮬레이션이 아닌 저비용 절차 메시다.
- 현재 얼굴 표정과 손가락 애니메이션은 없다.
- 다음 품질 단계는 새 모델 교체가 아니라 현재 리그에 보행·달리기·피격·표정 클립을 추가하는 것이다.
