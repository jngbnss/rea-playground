# 07. 사운드·BGM 수급 계획

> 상태: 초안 (조사일 2026-10-14). 큐 목록 원본: [`data/audio_cues.json`](../data/audio_cues.json)
> 출처별 라이선스는 [`data/license-ledger.csv`](../data/license-ledger.csv)의 `audio` 항목

사운드는 체감 품질의 절반이다. 특히 **타격음과 히트스톱이 같은 프레임에 맞으면** 같은 애니메이션도 훨씬 묵직해 보인다. 그래서 사운드 P0 큐는 5주차가 아니라 **3주차 완주 빌드부터** 들어간다.

## 1. 출처 전략

| 용도 | 1순위 | 라이선스 | 비고 |
|---|---|---|---|
| 국악 BGM·스팅 | [공유마당 국악 BGM](https://gongu.copyright.or.kr/gongu/wrt/wrtCl/listWrtSound.do?menuNo=200020&depth2ClSn=10033) (주식회사 아이티앤) | CC BY 4.0 | 분위기 태그("고요한" 등)로 고른다. **곡마다** 표기를 확인하고 대장에 곡 단위로 적는다 |
| 자연 환경음 | [공유마당 자연음](https://gongu.copyright.or.kr/gongu/wrt/wrtCl/listWrtSound.do?menuNo=200020&depth2ClSn=10128) | 공공누리 1유형 | 출처 표시 필수. 공공기관이 후원한 것처럼 보이는 표현 금지 |
| 발소리·칼·타격·UI | [Kenney](https://kenney.nl/assets/rpg-audio) RPG Audio, Impact Sounds, Interface Sounds | CC0 | 공개 저장소에 커밋해도 안전 |
| 장터 웅성거림·종이 | [Freesound](https://freesound.org/help/faq/) | **CC0·CC BY 파일만** | NC·Sampling+는 대장 검사에서 자동 차단 |
| 고품질 보강 | [Sonniss GDC 번들](https://sonniss.com/gdc-bundle-license/) | 자체 라이선스 | 빌드 포함은 가능. **원본 파일을 공개 저장소에 커밋하면 안 된다** → `audio/_private/`를 `.gitignore` |
| 도적 외침 | **팀 직접 녹음** | 팀 소유 | "웬 놈이냐!" 같은 한국어 외침은 구할 곳이 없다. 휴대폰 녹음 + 노이즈 제거로 충분 |

**쓰지 않는 출처:** 국립국악원 아카이브(개방 라이선스 없음), 공유마당 기증 커버곡(원곡 저작권 문제), Pixabay(원본을 공개 저장소에 두면 단독 재배포로 볼 여지가 있음).

## 3. 믹싱 규칙

- 버스 5개: Music, Ambience, SFX, Voice, UI. 기본 음량은 JSON의 `buses`.
- **대화 중 Music −6dB 덕킹**, 전투 BGM은 마지막 적이 쓰러지고 4초 뒤 이전 BGM으로 크로스페이드.
- 반복되는 소리(발소리, 휘두르기, 적중)는 **변형 3~4개 + 피치 ±5% 랜덤**. 같은 소리가 반복되면 바로 싸 보인다.
- 적중음은 고음(칼날)과 저음(쿵) 두 겹. 히트스톱 0.06초와 같은 프레임에 재생.
- 3D 음원(모닥불, 개울)은 감쇠 거리를 지형에 맞게 조정하고 Reverb 버스는 쓰지 않는다(범위 밖).

## 4. 일정

| 주차 | 할 일 |
|---|---|
| 1주차 | 공유마당 BGM 후보 곡 5~8개 청취 → 마을·전투 각 2곡으로 좁힘, 대장에 곡 단위 행 추가 |
| 3주차 | P0 큐 전부 임시 연결 (완주 빌드에 소리가 있어야 한다) |
| 5주차 | 도적 음성 녹음, P1 큐, 믹싱 1차 |
| 6주차 | 시연 PC 스피커·헤드폰 둘 다로 믹싱 확인 |

## 5. TTS (P2)

MeloTTS 코드와 MeloTTS-Korean 가중치 모두 MIT로 표기되어 있다. 다만 **한국어 처리 의존성의 라이선스와 학습 데이터 출처는 확인하지 못했다.** 계획서 규칙대로 품질·지연 기준을 통과할 때만 넣는다.

## 확인하지 못한 것

- 공유마당 기증 저작물의 정확한 조건, 공유마당 이용약관 전문
- 공유마당에 장터 웅성거림 소리가 있는지 (없으면 Freesound CC0로 대체)
- CC0 출처의 종이·두루마리 소리
- MeloTTS 한국어 의존성의 라이선스
