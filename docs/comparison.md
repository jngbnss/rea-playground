- 데모: `experiments/f1-recreation` (`npm run build` → `vite preview`, `http://localhost:4173`)

## 1. 가속 (W 유지, 정지 → 최대)

| 구간 | 원본 | 데모 | 차이 |
| --- | ---: | ---: | ---: |
| 0 → 100 km/h | 2.78 s | 2.34 s | 데모가 0.44 s 빠름 |
| 0 → 200 km/h | 5.22 s | 4.98 s | 데모가 0.24 s 빠름 |
| 0 → 250 km/h | 6.59 s | 6.71 s | 데모가 0.12 s 느림 |
| 7.0 s 시점 최고 | 256 km/h | 257 km/h | 거의 동일 |

**해석**

- **곡선 모양이 같다.** 저속에서 가파르고 고속으로 갈수록 완만해지는, `min(engineForce, P/v)`
  구조 특유의 형태가 양쪽 모두에서 나타난다. 250 km/h 부근에서 두 곡선이 교차한다.
- **저속 구간에서 데모가 더 빠른 이유** — 원본은 네 바퀴가 각각 레이캐스트 서스펜션으로
  하중을 받고, 그 하중에 비례한 그립 한계 안에서만 구동력이 노면에 전달된다.
  발진 시 하중 이동·휠스핀으로 실제 전달력이 `engineForce`보다 작다.
  데모는 자전거 모델이라 하중 이동이 없고, 접지 한계를 `μ·normalLoad` 하나로만 클램프한다.
- **고속에서 역전되는 이유** — 데모의 `dragCoefficient = 0.9`(자체 설계값)가 원본보다 크게 잡혀
  고속에서 저항이 더 빨리 커진다. 원본의 실제 계수는 차종 테이블에 있고 **[미확인]**이다.

## 2. 제동 (약 186 km/h에서 S 유지)

| 항목 | 원본 | 데모 |
| --- | ---: | ---: |
| 시작 속도 | 186 km/h | 187 km/h |
| 정지까지 | **2.10 s** | **2.62 s** |
| 평균 감속도 | ≈ 2.46 g | ≈ 1.98 g |

**해석** — 데모가 약 25 % 느리게 선다.

1. 원본은 제동력을 `brakeBias`로 앞/뒤에 나눈 뒤 **바퀴별 수직하중 기준 그립 한계**와 비교하고,
   초과하면 휠 락 처리까지 한다. 제동 중 앞쪽으로 하중이 이동해 앞 타이어가 더 큰 힘을 낸다.
2. 데모는 하중 이동이 없어 앞뒤 하중이 정적 배분 그대로다. 또 `brakeForce = m·g·4` **[분석확인]**를
   그대로 쓰면 μ=1.6 한계를 넘기 때문에 `μ·normalLoad`로 클램프했고(**[자체설계]**),
   그 결과 저속 구간에서 제동력이 원본보다 작아진다.
3. 두 경우 모두 **브레이크 압력 램프(상승 10/s)** 가 적용되어 처음 0.1초는 제동력이 차오른다.
   데모 첫 샘플에서 속도가 오히려 189 km/h로 살짝 오른 것이 그 구간이다.

## 3. 조향 반응

| 항목 | 원본 | 데모 |
| --- | --- | --- |
| 조향 즉시성 | 슬루율 제한 (꺾기 6.46/s, 복귀 8.12/s) | **동일 수식·동일 상수** |
| 고속 조향각 축소 | `maxSteerLowSpeed + (maxSteerHighSpeed·1.35 − low)·n(2−n)` | **동일 수식** |
| 측정된 고속 포화 조향각 | **[미확인]** (내부 값 접근 불가) | **0.162 rad** (= 0.12 × 1.35) |
| 107 km/h 시점 조향각 | **[미확인]** | 0.1754 rad |
| 정상 선회 요레이트 | **[미확인]** | 좌 +0.47 rad/s, 우 −0.50 rad/s |

**해석**

- 데모에서 측정한 포화 조향각 0.162 rad는 분석에서 도출한 식
  `maxSteerHighSpeed × highSpeedLock = 0.12 × 1.35`와 **정확히 일치**한다.
  → 조향 수식 재현이 의도대로 동작함을 수치로 확인했다.
- 원본의 조향각 실수치는 HUD에 노출되지 않고 번들 내부 변수로만 존재해 **비교 불가**다.
  `maxSteerLowSpeed / HighSpeed / FadeSpeed` 자체가 **[미확인]**이므로,
  "체감이 비슷한가"는 주관 평가일 뿐 수치 비교가 아니다.

## 9. 결론

- **입력 처리 → 명령 변환 → 카메라 → HUD** 계층은 분석에서 확인한 수식을 그대로 옮겼고,
  고속 포화 조향각 0.162 rad처럼 **예측값과 실측값이 일치**하는 지점에서 재현을 확인했다.
- **차량 동역학 계층**은 근사(자전거 모델)이므로 가속 곡선은 비슷하지만 제동은 25 % 차이가 난다.
  이 차이의 원인은 "하중 이동과 바퀴별 그립 한계의 부재"로 설명되며, 추측이 아니라
  두 구현의 코드 구조 차이에서 직접 따라 나온다.
- 즉 **느낌이 비슷한 부분은 수식을 공유해서이고, 다른 부분은 모델 차원이 달라서다.**

# 부록 · 라운드 3 재측정 (파라미터 확정 + 하중 이동 적용 후)

라운드 3에서 두 가지가 바뀌었다.

1. 1라운드에 **[미확인]**이라 자체 설계값으로 채웠던 차량 파라미터를 **번들에서 확정된 실제 값**으로 전부 교체
   (mass 800 kg, 휠베이스 3.4 m, enginePower 695.2 kW, drag 0.51362, downforce 2.784,
    steer `0.50 / 0.07 / 70`, brakeBias 0.56, μ 1.75/1.8025 — `03-vehicle-controls.md` 9절)
2. 제동 차이의 원인으로 지목했던 **종방향 하중 이동**과 **휠 락 판정**을 데모에 구현

원자료: `docs/evidence/r3-throttle-demo.csv`, `r3-throttle-original.csv`, `r3-brake-demo.csv`

## A. 가속 재측정

| 구간 | 원본 | 데모(R1) | 데모(R3) |
| --- | ---: | ---: | ---: |
| 0 → 100 km/h | 2.83 s | 2.34 s | **2.55 s** |
| 0 → 200 km/h | 5.33 s | 4.98 s | **4.96 s** |
| 0 → 250 km/h | 6.74 s | 6.71 s | **6.43 s** |
| 0 → 300 km/h | 미도달\* | — | 8.94 s |
| 관측 최고 | 293 km/h\* | 257 km/h (7 s) | 314 km/h (10.4 s) |

\* 원본은 12.9초 전력 가속 중 Melbourne 코스를 벗어나 293 km/h에서 감속했다.
**차량 한계가 아니라 트랙 한계**다. 직선 길이가 부족해 원본의 0→300은 측정할 수 없었다 → **[미측정]**.

**해석**

- 저속 구간 격차가 **0.44초 → 0.28초로 줄었다.** 하중 이동을 넣어 발진 시 뒤축(RWD 구동축)
  하중 변화가 반영된 결과다. 남은 격차는 원본의 바퀴별 서스펜션·휠스핀 모델 때문으로 본다.
- 중·고속은 거의 일치한다(0→200에서 0.37초 차, 약 7 %).
  확정된 `dragCoefficient = 0.51362`와 ERS 테이퍼를 반영하면서 라운드 1의 과대 항력(0.9)이 사라졌다.

## B. 제동 재측정 (약 186 km/h → 정지)

| | 원본 | 데모(R1) | 데모(R3) |
| --- | ---: | ---: | ---: |
| 소요 시간 | **2.10 s** | 2.62 s | **2.51 s** |
| 원본 대비 | — | +24.8 % | **+19.5 %** |
| 평균 감속도 | 2.46 g | 1.98 g | 2.06 g |

하중 이동 도입으로 격차가 **24.8 % → 19.5 %** 로 줄었다. 가설이 맞는 방향이었다는 뜻이지만
**원인의 전부는 아니었다.** 남은 19.5 %의 후보:

1. 원본은 바퀴 **4개 각각**에 레이캐스트 하중을 쓴다. 데모는 축 단위(2개)다 → 좌우 하중 차이가 없다.
2. 원본은 서스펜션 스프링/댐퍼(`springPerKg 56`, `damperPerKg 3.25`)로 하중이 **동적으로 진동**한다.
   데모는 1차 정적 식 `ΔW = m·ax·h/L`을 쓴다.
3. 데모는 액티브 에어로를 구현하지 않아 제동 시 다운포스 증가가 없다.

→ 이 셋은 **다음 라운드의 검증 대상**이지 결론이 아니다.

## C. 조향 포화각 — 예측 대 실측

확정된 F1 튜닝 `steer = [0.50, 0.07, 70]`과 1라운드에 읽어낸 식으로 계산한 고속 포화각:

$$\text{maxSteer}(v \ge 70) = 0.07 \times 1.35 = 0.0945\ \text{rad}$$

데모 실측 (82.2 m/s = 296 km/h, A 키 유지):

```
kmh=295  steerAngle=0.00000   (입력 직전)
kmh=296  steerAngle=0.04331   (슬루율 제한 중)
kmh=297  steerAngle=0.08401
kmh=297  steerAngle=0.09450   ← 포화
kmh=297  steerAngle=0.09450
kmh=296  steerAngle=0.09450
```

**예측 0.0945 rad, 실측 0.09450 rad — 완전 일치.**
슬루율 제한(약 0.155초)으로 서서히 도달하는 과정까지 1라운드 분석과 일치한다.

원본의 동일 값은 HUD에 노출되지 않아 **[미확인]**이다. 비교 대상은 "원본의 실측값"이 아니라
**"원본 코드에서 유도한 값"** 이며, 그것과 데모 실측이 일치한다는 뜻이다.

# 부록 · 라운드 4 재측정 (액티브 에어로 + 4륜 서스펜션 적용 후)

라운드 4에서 바뀐 것:

1. **액티브 에어로** 구현 — 발동 조건을 번들에서 확정해(`03-vehicle-controls.md` 11절)
   `drag ×0.7 / downforce ×0.55`를 열림 램프 0.5 s · 닫힘 램프 0.15 s 로 보간한다.
2. **4륜 레이캐스트 서스펜션** 구현 — 축 2개의 정적 하중이동 식을 버리고,
   차체 heave·pitch·roll 3자유도를 적분해 바퀴 4개의 수직 하중을 만든다
   (`springPerKg 56`, `damperPerKg 3.25`, `antiRollPerKg [120, 95]`, `rest 0.3` 전부 확정값).
   휠 락 판정과 마찰원도 **축 단위에서 바퀴 단위로** 내려갔다.

원자료: `docs/evidence/r4-throttle-demo.csv`, `r4-brake-demo.csv`

  그만큼 뒤축 접지 한계(`μ·rearLoad`)가 낮아지기 때문이다. 원본도 같은 분기를 가진다.
- 측정 중에는 데모의 월드 경계(`worldLimit 1900 m`)를 해제했다. 평지 데모라 경계에 닿으면
  속도를 절반으로 깎는 안전장치가 걸려 고속 수렴을 볼 수 없다(E-019).

# 부록 · 라운드 5 재측정 (브레이크 보조 + 바퀴별 힘 해석 전체 이식)

라운드 4가 남긴 가설 "제동 격차 15.7 %는 원본의 `brakeAssist` 분기 때문"을 검증하려고
번들의 **바퀴 힘 해석 블록 전체**를 다시 읽었고, 추정으로 채웠던 값이 여럿 **오류**로 드러났다
(`03-vehicle-controls.md` 13절).

원자료: `docs/evidence/r5-throttle-demo.csv`, `r5-brake-assist-on.csv`, `r5-brake-assist-off.csv`
화면: `docs/evidence/r5-brake-assist.png` (HUD `ABS` 표시 · 락 없음)

## A. 제동 (약 186 km/h → 정지)

| | 원본 | R3 | R4 | **R5 보조 ON(원본 기본)** | R5 보조 OFF |
| --- | ---: | ---: | ---: | ---: | ---: |
| 소요 시간 | **2.10 s** | 2.51 s | 2.43 s | **1.94 s** | 2.35 s |
| 원본 대비 | — | +19.5 % | +15.7 % | **−7.6 %** | +11.9 % |
| 평균 감속도 | 2.46 g | 2.06 g | 2.17 g | **2.72 g** | 2.24 g |
| 휠 락 | — | 앞·뒤 | 앞·뒤 | **없음**(보조가 막는다) | 앞·뒤 |

- **격차의 부호가 뒤집혔다.** 라운드 4까지는 데모가 느렸는데, 확정값(`brakeForceScale 1.5`,
  `brakeGrip 1.2`, 보조 ON)을 넣으니 이제 **원본보다 빠르다**. 크기는 15.7 % → 7.6 %로 줄었다.
- 남은 차이의 후보는 데모가 **1로 두고 있는 두 계수**다: 노면 그립 `surfaceGrip`(레이싱 라인 밖에서 1 미만)과
  타이어 마모 `tyres.grip(i)`. 둘 다 1보다 작으면 `w`가 줄어 제동이 느려진다. 원본 측정은
  실주행 중 값이라 두 계수가 1이었다는 보장이 없다 — **[미확인]**.
- 하중 민감도 `x *= 1 - 0.08*(min(load/avgLoad, 2.5) - 1)` 도 아직 미구현이다.
